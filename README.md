## What's here
- `index.html` — the single-page site (hand-built, no frameworks or templates).
- `Al_Schramm_Resume.pdf` — downloadable one-page résumé.

## Design notes
- Editorial / print-inspired direction: warm paper, Fraunces serif display, terracotta accent.
- Accessible by design: skip link, visible focus styles, working mobile navigation,
  count-up + scroll-reveal animations that all respect `prefers-reduced-motion`.
- Delight layer (custom cursor, warm spotlight, magnetic buttons, card tilt) is gated to
  fine-pointer devices with motion enabled — keyboard, touch, and reduced-motion users get
  a clean native experience.
